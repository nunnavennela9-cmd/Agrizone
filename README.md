# Agrizone - Smart Agriculture Platform

Agrizone is a full-stack smart agriculture web application designed to help farmers and agricultural managers manage crop data, location details, and regional information efficiently.

## Features

- Add and manage agricultural crop records
- Interactive location mapping for Indian districts and mandals
- Secure authentication and database operations via Supabase
- Responsive and modern user interface

## Technologies Used

- React (Frontend UI)
- TypeScript (Type safety)
- Tailwind CSS (Styling)
- Vite (Build tool)
- Supabase (Backend & Database)

## How It Works

The application interacts with Supabase backend services to execute database operations. Regional data like districts and mandals are organized using structured SQL migrations, providing real-time data updates across the UI components.

## Setup

1. Clone the repository to your local machine
2. Run `npm install` to install required dependencies
3. Set up environment variables for Supabase keys
4. Run `npm run dev` to start the local development server
